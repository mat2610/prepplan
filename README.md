# PrepPlan

אפליקציית ווב לתכנון meal-prep שבועי: תפריט, רשימת קניות ותוכנית בישול שעומדים ביעד התזונתי, בתקציב ובזמן הבישול של המשתמש.

פרויקט סיום בקורס **מבוא לבינה מלאכותית**, הקריה האקדמית אונו.

## מה האפליקציה עושה
1. המשתמש בוחר מטרה (עלייה במסה / שמירה / חיטוב) ומשקל, ומקבל יעד קלוריות וחלבון.
2. מגדיר תקציב שבועי, זמן בישול ומספר ימים.
3. מסמן מה כבר יש במטבח, מה הוא לא אוכל, ויכול לכתוב בקשה חופשית ("משהו אסייתי, בלי טונה").
4. מקבל תפריט שבועי, רשימת קניות עם מחירים ממוצעים בישראל, ומתכונים עם כמויות.

## איך זה עובד
- **אופטימיזציה (תכנון לינארי בשלמים):** בוחרת כמה מנות מכל מתכון כך שכל האילוצים מתקיימים (קלוריות ±5%, חלבון, תקציב, זמן, גיוון). זמן הבישול נספר פעם אחת לכל מתכון ולא לכל מנה.
- **Gemini:** מבין בקשות בשפה חופשית, יוצר מתכונים חדשים וכותב לוח זמנים לבישול. הוא לא קובע את המספרים: קלוריות וחלבון מחושבים מחדש מטבלת הערכים ומושווים למה ש־Gemini טען.
- **כשאין פתרון:** כל אילוץ מוסר בנפרד והאפליקציה אומרת מה צריך לשנות.

```
js/model.js                מודל האופטימיזציה, רשימת קניות, בדיקת מתכוני Gemini

img/logo.svg               לוגו
```

## הרצה
- **אונליין:** הקישור ב־GitHub Pages.
- **מקומית:** לפתוח את `index.html` בדפדפן. הכול עובד גם בלי אינטרנט, חוץ מ־Gemini.

## מקורות נתונים
- ערכים תזונתיים: מאגר "צמרת" של משרד הבריאות, USDA FoodData Central.
- מחירים: ממוצעים בסופרמרקטים בישראל, אוקטובר 2026 (עוגנים: Numbeo, 2.10.2026). מעוגלים, לא מדויקים לשקל.

## מגבלות ידועות
- מחירים אינם בזמן אמת.
- אין חשבונות משתמש; שבועות שמורים נשמרים בדפדפן בלבד.
- אין מעקב אחרי מה שנאכל בפועל.
